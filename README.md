# The Reboot Eclipse

A Berserk-inspired profile dashboard built using **GraphQL**, JavaScript, HTML, and CSS.

The application authenticates users through the Reboot GraphQL API and displays their profile information, progress, statistics, and activity data through a custom dashboard.

## Live Demo

🔗 **[View The Reboot Eclipse](https://abdulazizahmed05.github.io/graphql/)**

## Features

- JWT authentication using the GraphQL API
- User profile and identification information
- Level and latest project completion
- Audit ratio statistics
- Total XP tracking
- Pass / fail project visualization
- Interactive SVG pie chart
- XP progression graph based on transaction dates
- Transaction details displayed on graph hover
- Detailed user information modal
- Background audio controls
- Responsive design
- Berserk-inspired visual design

## Charts

### Pass / Fail Chart

The pass/fail statistics are displayed using a custom SVG donut chart. The chart calculates the percentage of successfully completed projects and visually represents the passed and failed portions.

### XP Progression Graph

The XP graph displays the user's XP progression over time.

Each point represents an XP transaction and is positioned according to:

- The date of the transaction
- The user's total XP at that point

Hovering over a point displays information about the transaction, including its name, type, XP amount, total XP, and date.
